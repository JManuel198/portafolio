# Manuel Jauregui — Portafolio Web Personal

Portafolio web personal diseñado para mostrar mis proyectos, habilidades y perfil profesional como desarrollador frontend. El objetivo es que cualquier reclutador, cliente o colega pueda conocer mi trabajo de forma clara y directa.

**Demo en vivo:** [portafolio-nu-ecru-27.vercel.app](https://portafolio-nu-ecru-27.vercel.app/)

---

## Objetivo

Soy Manuel Jauregui, estudiante de Análisis de Sistemas y desarrollador frontend autodidacta. Este sitio centraliza todo lo que sé hacer: desde interfaces limpias en HTML/CSS hasta módulos personalizados en Odoo. Está pensado para mostrar que aprendo haciendo y que cada proyecto tiene un propósito real.

---

## Secciones

| Sección | Descripción |
|---|---|
| **Sobre mí** | Quién soy, cómo trabajo y hacia dónde voy |
| **Proyectos** | Trabajos reales con links a demo y código fuente |
| **Skills** | Tecnologías que manejo |
| **Contacto** | Formulario funcional para colaboraciones o propuestas |

---

## Proyectos destacados

- **Módulo de gestión para taller de reparaciones** — Módulo personalizado en Odoo 18.0 para la gestión integral de un taller. Stack: Python, XML, Odoo.
- **Portafolio Personal Web** — Este mismo sitio. Stack: HTML, CSS, JavaScript.
- **Portafolio Web Juan Arocha** — Sitio minimalista para fotógrafo urbano ficticio. Stack: HTML, CSS, JavaScript.
- **Raiz Coffee** — Landing page para cafetería ficticia con diseño moderno. Stack: HTML, CSS, JavaScript.
